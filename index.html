01 — About

A builder at the intersection of software, systems, and community.

I'm a Computer Science undergraduate at The Catholic University of America (minor in Mathematics) drawn to full-stack work that actually ships — sites that give small businesses a real online presence, backends that hold up under load, and interfaces people trust enough to come back to.

Right now that means a senior year in machine learning, cloud computing, and databases, plus a senior design project building an AI-guided academic search interface. Alongside classes I run a freelance web development practice serving small businesses across the DMV — scoping, design, launch, and the cold calls that make it all start.

I'm bilingual (Spanish native), community-driven, and just back from a semester at the University of Galway in Ireland. I care about clear code, honest client communication, and building things that outlast the deploy.

Project / 002

LocalAid Connect

A full-stack web app that helps people find nearby community resources — food banks, medicine & vaccines, shelter, legal support. React front end, Node/Express + SQLite backend, with location-based search wired up through Google Maps/Places. REST APIs were designed to append new resources dynamically as they're found — no fixed database cap, so coverage grows as the community adds to it.

React Node.js Express SQLite Google Maps API

Network Vulnerability Scanner

Built a scanner that sweeps the full TCP port range per target, then ranks findings and auto-generates PDF remediation reports — cutting manual triage time versus checking ports individually. Modular scanning workflows and results aggregation with actionable remediation notes.
